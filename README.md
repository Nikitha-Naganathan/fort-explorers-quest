Vellore Fort Chronicles

A 3D educational adventure set in Vellore Fort, with desktop app packaging via Electron. Features:

Title screen with character creation (pick a historical archetype like Sepoy or Nayaka Guard, set a custom name, starting stats).
3D exploration of Vellore Fort with architectural detail (stone ramparts, moat, temple complex with carved pillars).
Level 1 ("Secrets of the Moat & Manuscripts"): intro narrative, NPC dialogue, a sword-drill mini-game, a manuscript-restoration puzzle, and moat-related tasks.
Level 2 ("The Siege of Vellore"): cutscene, timed rampart defence, tactical puzzles, garrison coordination.
A "Discoveries" journal tracking fort lore learned along the way.
Electron packaging for a downloadable desktop build.
