# Vellore Fort Chronicles

Build 'Beyond the Bastions', a 3D educational adventure game set in Vellore Fort, configured with Electron desktop app packaging. Features include:
1. Title screen with character creation (choose historical character archetype like Sepoy or Nayaka guard, enter custom player name, starting stats).
2. 3D WebGL exploration of Vellore Fort with authentic architectural details (stone ramparts, moat, temple complex with Yali-carved pillars).
3. Level 1 ('Secrets of the Moat & Manuscripts'): Intro narrative sequence, NPC interactions, sword training mini-game/drills, manuscript deciphering jigsaw puzzles, and crocodile moat-related tasks.
4. Level 2 ('The Siege of Vellore'): Story cutscene, enemy attack where players navigate the bastions, solve tactical puzzles, coordinate garrison defenses, and repel invaders.
5. Educational historical codex/journal tracking Vellore Fort lore learned along the way.
6. Electron build packaging setup and downloadable desktop release instructions.
